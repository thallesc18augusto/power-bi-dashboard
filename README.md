# Power BI Sales Dashboard

## Project Overview

Interactive business intelligence dashboard developed using Microsoft Power BI to analyze sales performance and support data-driven decision-making.

## Objectives

- Monitor key performance indicators (KPIs).
- Analyze sales trends and performance.
- Identify business patterns and opportunities.
- Transform raw data into actionable insights.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Modeling
