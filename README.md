# Healthcare Performance Dashboard

## Project Overview

An interactive Healthcare Performance Dashboard developed using Microsoft Power BI to provide insights into healthcare operations, patient demographics, clinical diagnoses, provider and facility performance, and financial performance.

The dashboard is organized into five sections to support data exploration, performance monitoring, and data-driven decision-making.

## Dashboard Sections

### 1. Executive Summary
Provides a high-level overview of key healthcare performance indicators.

### 2. Patient Overview
Presents insights into patient demographics, patient volume, and related metrics.

### 3. Clinical Diagnosis
Explores clinical diagnosis data and identifies patterns across patient conditions.

### 4. Provider & Facility
Analyzes performance across healthcare providers and facilities.

### 5. Financial & Payer
Provides an overview of financial metrics and payer-related performance.

## Tools & Technologies

- Microsoft Power BI
- Data Visualization
- Business Intelligence
- Data Analysis
